# Sachin Yadav - Personal Developer Portfolio

A responsive, high-performance personal portfolio website built with **React**, **Tailwind CSS**, and **Vite** for **Sachin Yadav**, B.Tech IT student at ABES Engineering College (2023–2027) and Aspiring MERN Stack Developer.

---

## 🚀 Live Preview & Features

- **Mobile-First & Ultra-Responsive**: Optimized for every screen size from smartphones to ultra-wide desktop monitors.
- **Dark / Light Mode**: Smooth theme toggling with automatic system preference detection and `localStorage` persistence.
- **Sticky Blur Navbar**: Glassmorphic header with scroll spy and animated mobile navigation drawer.
- **Hero Section**: Eye-catching gradient typography, animated status indicator, direct resume/contact CTAs, and interactive code box.
- **About & Education**: Academic background at ABES Engineering College (2023–2027), core Computer Science coursework, and engineering pillars.
- **Interactive Skills Section**: Categorized filter tabs (Frontend, Backend & APIs, Databases, Languages & Tools) with visual badges and level indicators.
- **Featured Projects**: Detailed cards for **Expense Tracker (MERN Stack)** and **Backend Ledger System (Node.js/Express.js)** with live demos, source code repositories, and an interactive Project Detail modal.
- **Achievements & Certifications**: Visual milestones for **LeetCode 150+ Problems (Java DSA)**, **Code-War Hackathon Finalist**, and **HackerRank React & Python Certificates**.
- **Interactive Contact Form & Socials**: Real-time form feedback, one-click copy email button, and direct links to GitHub, LinkedIn, and LeetCode.
- **Interactive Resume Modal**: Recruiter-friendly resume view with print and PDF download support.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS v4, Lucide React Icons
- **Tooling & Build**: Vite 8, Oxlint
- **Deployment Ready**: Vercel / Netlify / GitHub Pages

---

## 💻 Getting Started Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

---

## ⚙️ Customization

All portfolio data (bio, links, projects, achievements, skills, and contact info) is centralized in:
```
src/data/portfolioData.js
```
Simply edit this file to update any information, project links, or social profile URLs.
